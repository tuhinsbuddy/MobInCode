#  Insurance Policy App

Build an insurance-policy list and details flow using SwiftUI, async/await, MVVM, repository pattern, loading/error states, cancellation and an actor-backed cache.

Build a small Insurance Policy Dashboard.
1. The user should be able to:
2. View all policies
3. See loading, empty, success, and error states
4. Open policy details
5. Renew an eligible policy
6. Retry failed requests
7. Avoid duplicate renewals
8. Handle cancellation and caching
